# Lapta Game TWA — Design Spec v1.0

> Полная спецификация редизайна Telegram Web App для турнира «Летний Кубок по лапте 2026»  
> Стиль: советский конструктивизм × современный спортивный брендинг

---

## 1. Характеристика стиля

Бренд Lapta Game построен на эстетике **советских спортивных плакатов 1920–1930-х**, осовремененной инструментарием streetwear-дропов и neosport-брендинга.

Ключевые маркеры:
- **Диагональные цветовые блоки** — красный и синий клинья рассекают кремовый фон под углом ~20–30°, создавая динамику без иллюстраций
- **Grain-текстура** — шум 30–40% opacity поверх фона убирает «цифровую пластиковость», добавляет тактильность
- **Aqum ALL-CAPS** — закруглённый конденсированный гротеск, все заголовки набраны капслоком с tight letter-spacing
- **Круговой badge-логотип** — «БЕЙ / LAPTA GAME / БЕГИ» по кругу — единственный декоративный элемент
- **Маркер-полоса** — горизонтальная бегущая строка из повторяющихся слов-дескрипторов («СТАВКИ · МАТЧИ · ОЧКИ ·») в нижней части экрана или между секциями
- **Высокий контраст** — текст почти всегда либо #F2E6D8 на тёмном, либо #1E1D3F на кремовом; промежуточных тонов минимум
- **Vintage-фото** — зернистые ч/б или duotone изображения игроков (опционально, только на главной)

## 2. Дизайн-система

### 2.1 Палитра

| Переменная CSS        | Hex       | Назначение |
|-----------------------|-----------|------------|
| `--lp-primary`        | `#D90D32` | Акцент, CTA-кнопки, live-бейджи, активные состояния |
| `--lp-secondary`      | `#1B65A6` | Вторичные кнопки, выигрышные бейджи, выделение |
| `--lp-bg`             | `#F2E6D8` | Основной фон (кремовый) |
| `--lp-contrast`       | `#1E1D3F` | Текст на кремовом, тёмный фон секций |
| `--lp-cream-dark`     | `#D9C9B5` | Разделители, инпуты, второй слой карточек |
| `--lp-text-on-dark`   | `#F2E6D8` | Текст поверх тёмного/цветного фона |
| `--lp-text-muted`     | `#8a7c6e` | Hint-текст на кремовом |
| `--lp-won`            | `#1B65A6` | Синий = выигрыш (нестандартно, но в бренде именно так) |
| `--lp-lost`           | `#D90D32` | Красный = проигрыш |
| `--lp-pending`        | `#8a7c6e` | Ожидание — нейтральный |

> **Примечание о TWA**: Telegram передаёт `--tg-theme-*` переменные. Мы их игнорируем/переопределяем через собственный root, кроме `--tg-safe-area-inset-*`.

### 2.2 Типографика

**Основной шрифт заголовков — Aqum** (если нет лицензии — fallback: `'Bebas Neue', 'Anton', sans-serif`)

```css
@font-face {
  font-family: 'Aqum';
  src: url('/fonts/Aqum.woff2') format('woff2');
  font-weight: 700;
  font-display: swap;
}
```

| Уровень         | Шрифт  | Размер | Weight | Transform   | Tracking |
|-----------------|--------|--------|--------|-------------|----------|
| H1 (страница)   | Aqum   | 32px   | 700    | uppercase   | 0.05em   |
| H2 (секция)     | Aqum   | 22px   | 700    | uppercase   | 0.03em   |
| Label/badge     | Aqum   | 12px   | 700    | uppercase   | 0.08em   |
| Body (основной) | System | 15px   | 400    | none        | normal   |
| Body (мелкий)   | System | 13px   | 400    | none        | normal   |
| Mono (коды)     | Monospace | 16px | 600  | uppercase   | 0.2em    |
| Odds/цифры      | Aqum   | 24px   | 700    | none        | -0.02em  |

**Системный стек (body):** `'SF Pro Text', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

│  ┌────────────────────────────────┐    │

- При динамическом обновлении (polling) — небольшое число мигает на 0.3s при смене значения
- Закончившийся матч — `opacity: 0.6`, результат выделен победившей команды bold

## 4. TabBar — детальная спецификация

```
┌─────┬──────┬──────┬──────┬──────┐
│  🏠  │  🏆  │  💰  │  🎁  │  📊  │  ← иконки
│ДОМ  │ МАТЧИ│БАЛАНС│БОНУСЫ│РЕЙТИНГ│  ← Aqum 9px uppercase
└─────┴──────┴──────┴──────┴──────┘
```

- Фон: `#1E1D3F` (contrast navy)
- Активная вкладка: иконка + текст `#D90D32`, small red dot indicator сверху

## 6. Реализация — план

### 6.1 Подготовка (CSS/шрифт)

1. Добавить `Aqum.woff2` в `/frontend/public/fonts/`
2. Создать `/frontend/src/styles/lapta.css` — все CSS-переменные и базовые классы
3. Импортировать в `main.tsx` вместо существующих Tailwind-только стилей
4. Добавить grain-SVG как data URI в `lapta.css`

### 6.2 Порядок редизайна страниц

1. `lapta.css` — дизайн-система (переменные, компоненты, типографика)
2. `TabBar.tsx` — тёмный, применяется везде
3. `Registration.tsx` — первый экран = первое впечатление
4. `Home.tsx`
5. `Matches.tsx`
6. `BetFlow.tsx`
7. `Balance.tsx`
8. `Bonuses.tsx`
9. `Leaderboard.tsx`
10. `PublicOddsPage.tsx` — финальная полировка

### 6.3 Стратегия: Tailwind vs custom CSS

Использовать **гибридный подход**:
- Tailwind остаётся для spacing/flex/grid утилит
- Все цвета и типографика переходят на `var(--lp-*)` custom properties
- Компоненты через `.lp-*` классы в `lapta.css`
- Удалить все `text-tg-*`, `bg-tg-*`, `border-tg-*` классы
