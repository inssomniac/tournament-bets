# Task: Летний Кубок по лапте 2026 — TWA Букмекер

## Контекст

Университетский турнир по лапте. Внутренняя платформа для ставок на виртуальные очки.
Заказчик — не технарь. Всё управление через UI.

- **Дедлайн:** 3 июня 2026
- **Разработчик:** 1 человек
- **Пользователей:** до 100 одновременно
- **Матчей:** 10–15 за турнир

---

## Стек

| Слой | Технология |
|------|-----------|
| Frontend (TWA) | React + Vite + Telegram Web App SDK |
| Backend | FastAPI (Python) |
| БД | PostgreSQL |
| Бот | python-telegram-bot или aiogram |
| Хостинг | VPS (купить) + Nginx + SSL (Let's Encrypt) |
| Деплой | Docker Compose |

---

## Архитектура

```
Telegram Bot
  ├── /start → проверка подписки на канал "Лапта 2026"
  ├── Кнопка "Открыть приложение" → запуск TWA
  └── Рассылка уведомлений о результатах матчей

TWA (React)
  ├── Экран регистрации (ввод ФИО)
  ├── Главное меню
  ├── Матчи + ставки
  ├── Баланс
  ├── Бонусы (подписка на каналы)
  └── Лидерборд

Admin Panel (отдельный React-роут /admin)
  ├── Доступ по Telegram ID (список в конфиге)
  ├── CRUD матчей (команды, коэффициенты, дедлайн ставок)
  ├── Ввод результатов → триггер выплат + уведомлений
  └── Управление бонусными каналами (фиксированный список)

FastAPI Backend
  ├── /api/auth — валидация Telegram initData
  ├── /api/users — регистрация, баланс
  ├── /api/matches — список, ставки
  ├── /api/bets — создание ставки
  ├── /api/bonuses — проверка подписки на канал, начисление
  ├── /api/leaderboard — топ пользователей
  └── /api/admin — защищённые эндпоинты для админки
```

---

## Модели данных

### User
```
id, telegram_id, full_name, balance, registered_at, bonus_received
```

### Match
```
id, team1_name, team2_name, odds_team1, odds_team2, 
bet_deadline, status (upcoming/active/finished), winner (null/1/2)
```

### Bet
```
id, user_id, match_id, team_choice (1/2), amount, 
potential_win, status (pending/won/lost), created_at
```

### BonusChannel
```
id, channel_id, channel_name, channel_url, bonus_points
```

### UserChannelBonus
```
user_id, channel_id, claimed_at
```

## Функциональные требования

### Пользователь

**Онбординг:**
- [ ] Проверка подписки на "Лапта 2026" при /start
- [ ] Регистрация: ввод ФИО
- [ ] Начисление 1000 стартовых + 100 бонусных очков при регистрации

**Ставки:**
- [ ] Список матчей со статусом, командами, коэффициентами, дедлайном
- [ ] Одна ставка на матч (нельзя изменить после подтверждения)
- [ ] Сумма ставки: 10–500 очков
- [ ] Проверка баланса перед ставкой
- [ ] Отображение потенциального выигрыша
- [ ] После дедлайна — ставки заблокированы

**Баланс:**
- [ ] Текущий баланс
- [ ] История ставок (матч, команда, сумма, статус)

**Бонусы:**
- [ ] Подписка на фиксированный список каналов → начисление очков
- [ ] Одноразово на пользователя по каждому каналу
- [ ] Проверка подписки через Telegram Bot API

**Лидерборд:**
- [ ] Топ пользователей по балансу
- [ ] Подсвечивать позицию текущего пользователя
- [ ] Обновление в реальном времени (polling или SSE)

### Организатор (Админка)

- [ ] Вход по Telegram ID (без пароля, ID в конфиге)
- [ ] Создать матч: команды, коэффициенты, дедлайн
- [ ] Редактировать матч (до начала приёма ставок)
- [ ] Ввести результат матча → автоматический пересчёт балансов
- [ ] После ввода результата → бот рассылает уведомления всем участникам ставки
- [ ] Просмотр всех ставок на матч

### Уведомления (Telegram Bot)

- [ ] Победа: "🎉 Ваша ставка на [команду] выиграла! +N очков"
- [ ] Поражение: "❌ Ваша ставка на [команду] проиграла. -N очков"
- [ ] (Опционально) Напоминание за 1 час до дедлайна

## Нефункциональные требования

- Telegram initData валидируется на бекенде (HMAC-SHA256) — обязательно
- HTTPS обязателен (TWA не работает без него)
- JWT или сессии для авторизации после валидации initData
- Все операции с балансом — атомарные (транзакции в БД)
- Защита от двойной ставки на уровне БД (unique constraint: user_id + match_id)

## Инфраструктура (нужно сделать)

- [ ] Купить VPS (минимум: 1 vCPU, 1GB RAM, 20GB SSD — хватит для 100 юзеров)
- [ ] Настроить домен + SSL (Let's Encrypt через Certbot)
- [ ] Nginx как reverse proxy (React → /,  FastAPI → /api)
- [ ] Docker Compose: postgres + backend + frontend + nginx
- [ ] Создать бота в BotFather, получить токен
- [ ] Настроить бота как TWA (set_web_app_info с URL приложения)

**Рекомендации по VPS:**
- DigitalOcean / Hetzner / Timeweb — от $5–7/мес
- Hetzner CAX11 (ARM) — дешевле всего при хорошей производительности

## Риски

| Риск | Вероятность | Митигация |
|------|------------|-----------|
| Telegram API для проверки подписки нестабилен | Средняя | Кеш результата на 10 мин |
| VPS не успеем купить/настроить | Низкая | Сначала локальная разработка с ngrok |

| Solo разработчик — нет буфера на болезнь | Средняя | Сдвинуть сложные фичи в конец |
