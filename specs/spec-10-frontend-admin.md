# Spec 10 — Frontend: Admin Panel

## Цель

Интерфейс для организатора турнира. Доступ по адресу `/admin`.
Организатор: не технарь, интерфейс должен быть простым и понятным.

## Доступ

Открывается в обычном браузере (не обязательно в Telegram).
При открытии `/admin` — инициализировать через тот же `/api/auth/validate`.

**Но:** организатор может открыть страницу вне Telegram (например на компьютере).
Решение — **два способа входа:**

1. Через Telegram (если открыт в TWA) — автоматически через `initData`
2. Через ввод Telegram ID вручную + dev-bypass (только в dev-режиме)

В продакшне: организатор открывает `/admin` через кнопку в Telegram-боте.

```python
# Добавить в bot/handlers/start.py
# Если пользователь является администратором — показывать дополнительную кнопку
if user_id in settings.admin_ids_list:
    keyboard.inline_keyboard.append([
        InlineKeyboardButton(
            text="⚙️ Панель организатора",
            web_app=WebAppInfo(url=f"{settings.TWA_URL}/admin")
        )
    ])
```

## AdminApp.tsx

```typescript
import { Routes, Route, Navigate } from 'react-router-dom'
import AdminAuthGate from '../../components/AdminAuthGate'

export default function AdminApp() {
  return (
    <AdminAuthGate>
      <Routes>
        <Route path="/" element={<Dashboard />} />
        <Route path="/matches" element={<MatchList />} />
        <Route path="/matches/new" element={<MatchForm />} />
        <Route path="/matches/:id/edit" element={<MatchForm />} />
        <Route path="/matches/:id/result" element={<MatchResult />} />
        <Route path="/users" element={<UserList />} />
        <Route path="*" element={<Navigate to="/admin" />} />
      </Routes>
    </AdminAuthGate>
  )
}
```

## AdminAuthGate

Валидирует JWT и проверяет `is_admin`. Если нет — редирект или сообщение об ошибке.

```typescript
export default function AdminAuthGate({ children }) {
  const [status, setStatus] = useState<'loading' | 'ok' | 'forbidden'>('loading')

  useEffect(() => {
    const init = async () => {
      try {
        const initData = window.Telegram?.WebApp?.initData || `dev:${ADMIN_TG_ID}`
        const { data } = await api.post('/api/auth/validate', { init_data: initData })
        
        if (!data.is_admin) { setStatus('forbidden'); return }
        
        api.defaults.headers.common['Authorization'] = `Bearer ${data.access_token}`
        setStatus('ok')
      } catch {
        setStatus('forbidden')
      }
    }
    init()
  }, [])

  if (status === 'loading') return <div>Проверка доступа...</div>
  if (status === 'forbidden') return <div>⛔ Доступ запрещён</div>
  return children
}
```

### MatchForm

Создание и редактирование матча. Один компонент для обоих случаев.

```
┌──────────────────────────────────┐
│ Новый матч / Редактировать матч  │
├──────────────────────────────────┤
│ Команда 1:  [Лаптевцы_______]   │
│ Коэф.:      [1.70___]           │
│                                  │
│ Команда 2:  [Медведи________]   │
│ Коэф.:      [2.20___]           │
│                                  │
│ Ставки принимаются до:          │
│ [15.06.2026] [14:00]            │
│                                  │
│ [Сохранить]     [Отмена]        │
└──────────────────────────────────┘
```

**Валидация на фронте:**
- Коэффициент: число от 1.01 до 10.00 (шаг 0.01)
- Дедлайн: не в прошлом
- Команды: не пустые

```typescript
// Отправка формы
const handleSubmit = async (values) => {
  if (isEdit) {
    await api.put(`/api/admin/matches/${matchId}`, values)
  } else {
    await api.post('/api/admin/matches', values)
  }
  navigate('/admin/matches')
}
```

**При редактировании:** данные матча загружаются из `GET /api/admin/matches` и предзаполняют форму.

## Стилизация

Простой, функциональный интерфейс. Не нужен красивый дизайн — нужна ясность.

- Таблицы: стандартные HTML-таблицы с Tailwind
- Кнопки: чётко подписаны, разные цвета для разных действий
  - Создать/Сохранить: `bg-blue-500`
  - Опасное действие (результат): `bg-red-500` с предупреждением
  - Отмена: `bg-gray-200 text-gray-700`
